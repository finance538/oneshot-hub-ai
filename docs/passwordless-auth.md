# الدخول برمز تحقق وقفل الجهاز

استُبدل الدخول عبر Google بدخول برمز تحقق (OTP)، وأُضيف قفل برمز سري وبصمة/Face ID
للمرات التالية. ربط Google Workspace (Drive) ما زال يعمل كما هو — المُلغى هو تسجيل
الدخول عبر Google فقط.

## كيف تعمل

1. يكتب المستخدم بريده الإلكتروني (أو رقم جواله متى فُعِّلت الرسائل).
2. يصله رمز من ٦ أرقام صالح ١٠ دقائق، مربوط بالمتصفح الذي طلبه.
3. بعد التأكيد تُنشأ الجلسة المشتركة لكل نطاقات `1shotcam.com`.
4. في أول دخول يُطلب منه تعيين رمز سري من ٦ أرقام، ثم تُعرض البصمة كاختصار فوقه.
5. بعد ١٠ دقائق خمول أو عودة من الخلفية، يُطلب الرمز السري أو البصمة — لا رمز تحقق جديد.

البصمة لا تُفعَّل إلا بعد وجود رمز سري، لأن مستشعراً معطلاً أو جهازاً جديداً يجب
ألّا يحبس صاحب الحساب خارج حسابه.

## متغيرات البيئة

### البريد — مطلوبة الآن

| المتغير | المثال |
| --- | --- |
| `OTP_SMTP_HOST` | `smtp.hostinger.com` |
| `OTP_SMTP_PORT` | `465` (أو `587`) |
| `OTP_SMTP_USER` | `no-reply@1shotcam.com` |
| `OTP_SMTP_PASSWORD` | كلمة مرور التطبيق |
| `OTP_MAIL_FROM` | `oneShot <no-reply@1shotcam.com>` |

قبل أن تُضبط هذه المتغيرات يرفض الخادم إرسال أي رمز ويُرجع `OTP_CHANNEL_UNAVAILABLE`
بدل الادعاء بأن رسالة أُرسلت.

### الجوال — اختيارية، تُفعِّل القناة فور ضبطها

إما Unifonic (الأنسب للسعودية):

| المتغير | المثال |
| --- | --- |
| `UNIFONIC_APP_SID` | من لوحة Unifonic |
| `UNIFONIC_SENDER_ID` | اسم المرسل المسجّل لدى هيئة الاتصالات |

أو Twilio:

| المتغير |
| --- |
| `TWILIO_ACCOUNT_SID` |
| `TWILIO_AUTH_TOKEN` |
| `TWILIO_FROM` |

لا يحتاج الكود أي تعديل عند التفعيل: `smsReady()` يرى المتغيرات ويفتح القناة،
وتظهر خانة الإدخال عندها بصيغة «البريد الإلكتروني أو رقم الجوال».

## الحدود المفروضة

| الحد | القيمة |
| --- | --- |
| صلاحية الرمز | ١٠ دقائق |
| محاولات الرمز الخاطئة | ٥ ثم يُلغى الرمز |
| طلبات الرمز لكل عنوان | ٤ في الدقيقة |
| طلبات الرمز لكل شبكة | ١٠ في الدقيقة |
| محاولات الرمز السري | ٥ ثم إيقاف ١٥ دقيقة |

الرموز وكلمات القفل تُخزَّن مُجزّأة بـ scrypt بملح خاص بكل سجل، فلا تمنح قراءةُ
قاعدة البيانات أحداً دخولاً صالحاً. ومفتاح البصمة العام وحده هو ما يُحفظ؛ المفتاح
الخاص لا يغادر المعالج الآمن في الجهاز.

## الترحيل

ملف الترحيل `netlify/database/migrations/20261105031955_mighty_stranger/` ينشئ:
`auth_codes` و`device_locks` و`device_passkeys` و`passkey_challenges`.

الحسابات القائمة تبقى كما هي: أول دخول برمز تحقق على نفس البريد يصل إلى الحساب
نفسه، ويؤكّده إن لم يكن مؤكداً (رسالة تأكيد Identity لم تكن تصل أصلاً).
